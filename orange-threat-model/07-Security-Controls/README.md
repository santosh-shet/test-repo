# 07 – Security Controls

## Overview

The **Security Controls** section documents the security measures implemented to protect the Orange Infrastructure Services supporting Tieto Banktech applications.

Building upon the identified threats and assessed risks, this section describes the preventive, detective, and corrective controls that help protect infrastructure, applications, data, and administrative activities.

The objective is to demonstrate how identified risks are mitigated and how the security posture of the environment is maintained over time.

---

# Objectives

The objectives of this section are to:

- Document the primary security controls protecting the environment.
- Describe monitoring and detection capabilities.
- Define how security controls are periodically validated.
- Support continuous improvement of the security posture.
- Demonstrate alignment between identified risks and implemented controls.
