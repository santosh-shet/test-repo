# 08 – Validation

## Overview

The **Validation** section ensures that the threat model remains accurate, relevant, and effective throughout the lifecycle of the Orange Infrastructure Services supporting Tieto Banktech applications.

Threat modelling is not a one-time activity. As the environment, business requirements, technologies, and threat landscape evolve, the threat model should be periodically reviewed and updated.

This section defines how the threat model is reviewed, how outstanding issues are tracked, and how continuous improvements are identified and managed.

---

# Objectives

The objectives of this section are to:

- Periodically review the threat model for accuracy and completeness.
- Track unresolved issues and follow-up actions.
- Identify opportunities for improving the architecture, security controls, and threat model.
- Ensure the threat model remains aligned with the current environment and organizational requirements.
- Support continuous security improvement.

# Validation Lifecycle

The threat model should be maintained as a living document through the following activities:

1. Review the threat model.
2. Validate assumptions and architecture.
3. Track open issues.
4. Update risks and security controls.
5. Identify improvement opportunities.
6. Repeat following significant changes or at regular review intervals.
