# References

## Overview

This appendix lists the standards, frameworks, methodologies, and guidance documents referenced throughout the Orange Infrastructure Services Threat Model supporting Tieto Banktech applications.

These references provide the basis for the threat modelling approach, risk assessment methodology, and security control recommendations used within this repository.
